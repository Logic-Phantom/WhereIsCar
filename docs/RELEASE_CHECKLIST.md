# 출시 체크리스트 (앱인토스 등록)

콘솔 작업·업로드·검수 요청은 소유자가 직접 한다(계정·약관 동의 필요).

## 1. 콘솔 앱 만들기
- [ ] [앱인토스 콘솔](https://apps-in-toss.toss.im/)에서 새 미니앱(비게임) 생성
- [ ] **앱 이름(appName): `whereiscar`** — 이미 쓰이면 다른 이름으로 만들고 `apps-in-toss.config.ts`·`src/platform/toss.ts` `APP_NAME` 둘 다 수정
- [ ] 표시 이름: `내 차 어딨지?`
- [ ] 앱 로고: `assets/brand/console-icon-600.png` (600×600)
- [ ] 한 줄 소개: `내 차 위치부터 예상 주차요금까지`
- [ ] 카테고리: 생활/유틸리티
- [ ] 권한 사용 목적
  - 위치: 주차한 위치를 기록하기 위해 버튼을 누를 때 한 번 확인합니다.
  - 카메라: 기둥·층 표지판 사진을 남기기 위해 사용합니다(선택).
  - 클립보드: 주차 위치 좌표를 복사하기 위해 사용합니다.
- [ ] 개인정보 처리방침·이용약관: 앱 안 설정 화면 문구 사용(`src/screens/Settings.tsx`)
- [ ] 문의 채널 등록

## 2. 번들 만들기·올리기
```bash
npm ci
npm test
npm run build:ait
```
- [ ] 생성된 `whereiscar.ait`를 콘솔에 업로드
- [ ] QR(샌드박스)로 iOS·Android 토스 앱에서 열기

## 3. 실기기 확인 (README 상태표에 기록)
- [ ] 첫 진입 시 권한 팝업이 뜨지 않는다
- [ ] 현재 위치 가져오기: 허용 / 거부 → 수동 저장 / 오차 표시
- [ ] 사진 찍기 → 저장 → 미니앱 완전 종료 후 재진입 시 사진 표시(사진 POC)
- [ ] 주차 저장 → 앱 종료 → 재진입 시 기록·타이머 이어짐
- [ ] 요금표 입력 → 예상 요금, 종료 후 실제 정산 금액 입력
- [ ] 지도에서 보기(카카오맵 열림) / 좌표 복사
- [ ] 토스 내비게이션 바 뒤로가기·홈, Safe Area, 하단 탭바 가림 없음
- [ ] 모든 기록 삭제 후 다른 데이터 영향 없음
