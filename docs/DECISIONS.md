# 결정 기록 (내 차 어딨지?)

원본 기획: `docs/SUPER_PROMPT.md`(파킹로그). 디자인 기준: `docs/design/reference.webp`(사용자 제공 시안).
API 근거는 설치된 `node_modules/@apps-in-toss/web-framework/dist/index.d.ts`(3.10.0)와 점심합의(lunchagree) 확인 결과를 따른다.

| ID | 결정 | 근거 |
|---|---|---|
| D-001 | 앱 이름 **파킹로그 → 내 차 어딨지?** 로 전부 변경. `appName`=`whereiscar`(콘솔 등록명과 같아야 함), 영문 부제 "Where's My Car" | 사용자 지시(2026-11-08). 저장소명 WhereIsCar와 맞춤 |
| D-002 | 앱인토스 WebView, Vite 8 + React 19 + TS strict, `@apps-in-toss/web-framework` **3.10.0**, `apps-in-toss.config.ts`(webBundleDir: dist) | 점심합의(3.9.0)와 같은 구조, npm 최신 안정판. SDK 3.x는 2.x로 롤백 불가 → 샌드박스·실기기 확인 후 출시 |
| D-003 | 프롬프트의 단일 흐름·탭바 없음 대신 **시안대로 홈/기록/설정 탭바 + 검색·타이머·요금표·통계 화면** 구현 | 사용자가 "첨부 이미지 레이아웃·디자인 그대로 재현" 명시. 탭바는 앱 내부 화면 전환용이며 토스 내비게이션 바(뒤로·홈)는 그대로 사용 |
| D-004 | 화면 안 뒤로가기 버튼은 **토스 밖(브라우저 미리보기)에서만** 표시 | 토스 내비게이션 바 뒤로가기와 중복 노출 금지(점심합의와 동일) |
| D-005 | 시안 1번(시작 화면)의 페이지 점(●○○)은 넣지 않음. 소개는 1장, 권한 요청 없음 | 캐러셀이 없는데 점을 두면 오해. 진입 즉시 권한·바텀시트 금지 정책 |
| D-006 | 시안 설정의 '알림 설정' → **'요금표 관리'**, '오픈소스 라이선스' 추가 | 로컬 알림 예약 API 없음·기능성 푸시는 서버(mTLS) 필요 → MVP 제외. 빈 메뉴 금지 |
| D-007 | 시안 검색 칩 '주차장/건물/지역' → **전체/주차장/층·구역/메모** | 건물·지역 분류 데이터가 없음(역지오코딩 미사용). 실제로 검색 가능한 필드 기준 |
| D-008 | 시안의 주소 줄('서울 서대문구 …') → **'GPS 기록됨 · 측정 오차 약 Nm' / '위치 직접 입력'** | 유료·외부 역지오코딩 미사용. 가짜 주소 금지 |
| D-009 | 저장: 토스 `Storage`(브라우저 미리보기는 localStorage). 키 `whereiscar.state.v1`(상태 JSON), `whereiscar.photo.<id>`(사진) | 서버·로그인 없음. 전체 삭제는 이 앱 키만 삭제(`clearItems` 사용 안 함) |
| D-010 | 완료 기록 **최근 50개**(프롬프트 5개에서 상향), 사진은 최근 10개 기록만, 요금표 5개, 최근 검색어 5개 | 시안의 기록 목록·검색·통계가 의미 있으려면 5개는 너무 적음. 메타데이터는 기록당 1KB 미만 |
| D-011 | 사진: `Device.openCamera({ base64: true, maxWidth: 1024 })` → 캔버스로 긴 변 720px JPEG, 350KB(문자열) 이하만 저장 | Storage 용량 한도가 문서에 없음 → 작게 제한. **실기기에서 재진입 후 표시 확인 필요(PHOTO POC)**. 실패 시 사진 버튼 숨김 |
| D-012 | 위치: `Device.getLocation({ accuracy: Accuracy.High })` 버튼 누를 때 1회. 실제 accuracy 보존, 50m 초과·미상이면 실내 경고 | 구독·백그라운드 위치 없음. 거부해도 수동 저장 |
| D-013 | 지도: 카카오맵 링크 `map.kakao.com/link/map/이름,lat,lng`를 `Device.openURL`로 열기 + **좌표 복사** 대체 | 서비스 오픈 정책 2-2 '단순 정보 확인을 위한 타사 웹사이트 이동' 허용(점심합의 D-042). 검수 지적 시 좌표 복사만 남김 |
| D-014 | 타이머 = `now - startedAt` 계산(화면 열린 동안 1초 갱신). 원형 링은 현재 1시간 안 진행률 | 백그라운드 타이머 없음. 시계가 시작보다 1분 넘게 이르면 '확인 필요' |
| D-015 | 요금: 무료 시간 → 기본 시간·요금 → 추가 단위(올림)·요금 → 1회 최대 요금. 기록마다 스냅샷 저장. 항상 '예상'·'사용자 입력 요금표 기준' 표기 | 프롬프트 §6.2. 일 최대요금·심야/주말·할인·회차는 계산 안 함. 결제 기능 없음 |
| D-016 | 실제 정산 금액은 종료 화면·상세에서 **화면 안 입력칸**으로 받음(`window.prompt` 미사용) | RN WebView에서 prompt 동작 보장 안 됨 |
| D-017 | 앱 아이콘 = **사용자 시안(`docs/design/reference.webp`) 왼쪽 위 아이콘을 그대로 잘라 사용**(x 64~274, y 25~235 실측). `npm run icons`(Pillow)로 콘솔 600px·앱 안 로고·파비콘·OG 생성 | 사용자 지시(2026-11-08). 직접 그린 SVG 아이콘은 폐기. 원본 해상도가 약 211px라 600px 확대 시 약간 부드러움 — 고해상도 원본을 받으면 교체 |
| D-018 | 프롬프트 권장 문서 16종 대신 **README(상태표·Work Log) + DECISIONS + RELEASE_CHECKLIST** 로 압축 | 같은 내용을 여러 문서에 흩지 않음. 출시 판단에 필요한 정보만 유지 |
| D-019 | `.npmrc legacy-peer-deps=true` | `@apps-in-toss/cli`(babel 7)와 `@vitejs/plugin-react`의 선택적 peer(babel 8) 충돌. 런타임 영향 없음 |
